# マネーフォワード クラウド連携

クラウド請求書の請求書を CRM の売上に、クラウド会計の仕訳を財務管理に取り込む仕組み。
管理画面は `https://accel-dash.com/mf`（社内メンバーのみ）。

## 流れ

```
クラウド請求書 ──(請求書API)──┐
                              ├── accel-dash /api/mf/sync ──▶ Supabase ──▶ CRM（売上）／財務管理（仕訳）
クラウド会計   ──(会計API)────┘         ▲
   ▲                                    │ 毎日 6:00 頃（Vercel Cron）＋ 画面から手動
クラウド給与 ──「給与から入力」（手動）─┘
```

- 請求書 → `crm_docs` の `revenues`（id は `mf-inv-<請求書ID>`、`source: "mf"`）
- 仕訳 → `finance_docs` の `journal`（id は `YYYY-MM`、月ごとに 1 件。財務管理の CSV 取り込みと同じ形）
- 請求書の取引先名 ↔ CRM 顧客の対応表 → `crm_docs` の `meta/mfmap`（CRM の画面で編集）

## 同期のルール

- 期間ごとの **上書き**。MF 側の修正・削除・入金状況の変化に追従する
- CRM で手入力した売上（id が `mf-inv-` で始まらない行）には触らない
- 顧客が変わっていなければ、CRM で直した事業・サービス・担当者・粗利は残す
- 取引先が顧客に紐づかない請求書も取り込む（customerId 空）。CRM の「売上管理 → 明細・内訳」で紐づける
- 財務管理の対象月は MF の内容で丸ごと置き換わる。勘定科目の区分（`fin/master`）は触らない

## 初回セットアップ

1. Supabase の SQL Editor で `supabase/mf.sql` を実行（`mf_connections` と `mf_sync_runs`。service_role 以外は読めない）
2. アプリポータル（app-portal.moneyforward.com）でアプリを登録。リダイレクト URI は
   `https://accel-dash.com/api/mf/callback` と `http://localhost:3000/api/mf/callback`、認証方式 CLIENT_SECRET_BASIC
3. Vercel の環境変数（Production）に次を入れる
   | 変数 | 値 | 種類 |
   | --- | --- | --- |
   | `MF_CLIENT_ID` | アプリポータルの Client ID | Config |
   | `MF_CLIENT_SECRET` | アプリポータルの Client Secret | Secret |
   | `CRON_SECRET` | `openssl rand -base64 32` で作った値。Vercel Cron がこれを付けて呼ぶ | Secret |
4. 再デプロイ後、`/mf` で「接続する」→ MF の認可画面で「許可」
5. 「今すぐ同期」で期間を指定して初回の取り込み（全期間なら数分）

## 環境変数

| 変数 | 必須 | 説明 |
| --- | --- | --- |
| `MF_CLIENT_ID` / `MF_CLIENT_SECRET` | 必須 | アプリポータルで発行 |
| `CRON_SECRET` | 自動同期に必要 | 無いと Cron からの呼び出しを拒否する（手動同期は動く） |
| `MF_REDIRECT_URI` | 任意 | 既定は `NEXT_PUBLIC_APP_URL` + `/api/mf/callback` |

## 使うスコープ（すべて読み取り）

`mfc/invoice/data.read` `mfc/accounting/journal.read` `mfc/accounting/offices.read` `mfc/accounting/accounts.read`

## 注意

- トークンは `mf_connections` にだけ置く。画面・ログ・チャットに出さない
- リフレッシュトークンは使うたびに新しくなる。同期を同時に 2 本走らせない（Cron と手動が重なると片方が 401 になることがある。その場合はもう一度実行すればよい）
- 会計の仕訳 API は「1 つの会計期間の中」でしか期間指定できないため、月単位で取っている
- 給与は API が無い。クラウド給与で月を確定 → クラウド会計「自動で仕訳 → 給与から入力」で登録 → 同期、の順
